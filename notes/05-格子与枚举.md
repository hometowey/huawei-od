# 格子与枚举

四问里的第四问前半。网格、图、依赖、组合方案，代码都是同一个递归，差别只在三个开关：

- 连通块：走进去就做标记，不撤销。
- 步数和层数：不用递归，用队列，一层一层走。
- 组合方案：选上之后递归，回来要撤销。

n ≤ 20 的方案计数、全排列，优先这一页，不要先写背包。本题库的销售方案、组装数组、短信优惠、猜密码，都是枚举。

## 开关一：网格连通

矿堆、消消乐、单入口空闲区域、机器人活动区域、可以组成网络的服务器、Linux 发行版（邻接矩阵当成图）。从一个没访问的格子出发，把整块加起来。

```python
DIRS = [(-1, 0), (1, 0), (0, -1), (0, 1)]

def solve_method(grid):
    n, m = len(grid), len(grid[0])

    def dfs(x, y):
        if not (0 <= x < n and 0 <= y < m):
            return 0
        if grid[x][y] <= 0:
            return 0
        val = grid[x][y]
        grid[x][y] = -1
        for dx, dy in DIRS:
            val += dfs(x + dx, y + dy)
        return val

    best = 0
    for i in range(n):
        for j in range(m):
            if grid[i][j] > 0:
                best = max(best, dfs(i, j))
    return best
```

标记用改格子，省掉 `visited` 集合。题面要求保留原网格时，另开 `seen = [[False]*m for _ in range(n)]`。

八方向的题（消消乐、五子棋相邻）把对角四个方向加进 `DIRS`。斜向连珠若只要一条直线上的长度，不要八方向乱走，按「四个轴分别延伸」：水平、竖直、主对角、副对角。最大相连男生数是后一种。

单入口空闲区域在 DFS 里多记一件事：碰到边界上空地，把这个边界坐标记为入口。整块搜完看入口列表的长度是不是 1。

单词搜索（找到它、找单词）是连通块和回溯的混合：格子要撤销，因为同一个字母不能重复用，但下一条路径还要用它。

```python
def dfs(x, y, k):
    if k == len(word):
        return True
    if not (0 <= x < n and 0 <= y < m):
        return False
    if seen[x][y] or grid[x][y] != word[k]:
        return False
    seen[x][y] = True
    for dx, dy in DIRS:
        if dfs(x + dx, y + dy, k + 1):
            return True
    seen[x][y] = False
    return False
```

## 开关二：步数用队列

病毒感染、火星改造、聚餐能不能走到、树上一层的节点、信号扩散如果要按距离衰减。递归 DFS 能走到，但「第几天」会被重复入队搞乱。用队列，每个点只进一次。

```python
from collections import deque

def solve_method(grid):
    q = deque()
    for i in range(n):
        for j in range(m):
            if grid[i][j] == START:
                q.append((i, j, 0))
                grid[i][j] = VISITED
    while q:
        x, y, day = q.popleft()
        for dx, dy in DIRS:
            nx, ny = x + dx, y + dy
            if not (0 <= nx < n and 0 <= ny < m):
                continue
            if grid[nx][ny] != EMPTY:
                continue
            grid[nx][ny] = VISITED
            q.append((nx, ny, day + 1))
    return day
```

多个感染源一起入队，天数自然就是多源最短。先入队的天数小，所以第一次到达就是最短。不要把 `day + 1` 写成全局加一后又对每个邻居各加一次。

「上一层的全部节点」同样是队列，只是邻居来自树的 children 字典，不是四方向。目录、树状查询、服务依赖若只问能到达谁，DFS 和 BFS 都可以；问第几层、最少步，用队列。

依赖成环（跳格子 1、微服务若允许环）：DFS 三色。没访问、正在访问、已经访问完。走到「正在访问」就是环。

```python
UNSEEN, IN, DONE = 0, 1, 2

def dfs(u):
    color[u] = IN
    for v in graph[u]:
        if color[v] == IN:
            return True
        if color[v] == UNSEEN and dfs(v):
            return True
    color[u] = DONE
    return False
```

快速建站那题要的是「入度为 0 的一批算一次部署」，是拓扑分层，仍然用队列：入度为 0 的入队，弹出时把后继入度减 1。层数就是答案。

```python
from collections import deque
q = deque(u for u in nodes if indeg[u] == 0)
steps = 0
while q:
    steps += 1
    for _ in range(len(q)):
        u = q.popleft()
        for v in graph[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
```

`for _ in range(len(q))` 是「这一批」的边界。漏了它，步数会变成节点数。

## 开关三：组合要撤销

和为 target 的 k 个数、硬件销售方案、组装新数组、云短信怎么充、MELON 均分、保密电梯的操作序列。

```python
def solve_method(nums, target, k):
    nums = sorted(nums)
    ans = []
    path = []

    def dfs(start, total):
        if len(path) == k:
            if total == target:
                ans.append(path.copy())
            return
        if total > target:
            return
        for i in range(start, len(nums)):
            if i > start and nums[i] == nums[i - 1]:
                continue
            path.append(nums[i])
            dfs(i + 1, total + nums[i])
            path.pop()

    dfs(0, 0)
    return ans
```

三个坑都在这段里：

- `path.copy()`。不复制的话，后面的 `pop` 会把已经存进去的方案改掉。
- 每个数只能用一次，下一层从 `i + 1` 开始。无限次使用才从 `i` 开始。
- 排序后跳过相同数字，否则方案重复。题面要的是种数还是具体方案，重复跳不跳不一样。

只问种数不问方案时，不用 `ans` 列表，用一个计数器。n ≤ 20 直接这么写。n 到了几百、只要一个最优值，改去 06 的背包。

全排列、第 N 个排列、考古学家拼碎片：n ≤ 10 时用标准库，不要手写。

```python
from itertools import permutations, combinations
candidates = permutations(chars, r)
candidates = combinations(nums, k)
```

猜密码、字母组合、AI 处理器在同一链路里选 k 个，本题库就是 `combinations`。

2^n 染色（无向图染色，n 很小）：外层 `for mask in range(1 << n)`，再检查每条边的两端是不是同时为红色。这是枚举，不是图论算法。

## 图只要「谁和谁一组」

We Are A Team、同班小朋友、广播能覆盖的服务器。人数不大时，用列表套集合做合并，和本题库标答一致，比背并查集快：

```python
teams = []
def find(x):
    for t in teams:
        if x in t:
            return t
    return None

ta, tb = find(a), find(b)
if ta is None and tb is None:
    teams.append({a, b})
elif ta is not None and tb is None:
    ta.add(b)
elif ta is None and tb is not None:
    tb.add(a)
elif ta is not tb:
    ta |= tb
    teams.remove(tb)
```

询问「是不是一组」就是看 `find(a) is find(b)`。人数上万再换成父亲数组的并查集，压缩路径。本题库这一类的 n 用上面的集合合并就够。

目录大小、服务失效、按路径替换二叉树：边是父子，不是四方向。DFS 的「邻居」改成 `children[u]`。

```python
def size(u):
    total = self_size[u]
    for v in children[u]:
        total += size(v)
    return total
```

## 写的时候对三件事

- 连通块不撤销，找单词和组合要撤销。这个开关写错，结果要么漏方案，要么一块被拆成很多块。
- 队列里的天数跟节点绑定。不要用一个全局 `day` 在 `for` 邻居时递增。
- 起点如果也算进答案，入队前就标记已访问。漏标记会把起点反复入队，病毒感染的天数会偏大。
