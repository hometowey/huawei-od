# 仿真与栈

四问里的第一问。题面在描述一台会跑的机器：编辑器、键盘、打印机、内存池、电梯、棋盘、报文、牌局。你要写的不是一个算法名字，是一份状态，加上「读入一条指令就改一次状态」。

本题库 100 分题里这一类最多。看到指令表、规则表、样例是逐步演示，就停在这一页。

## 骨架

```python
def solve_method(commands):
    state = initial_state()
    for cmd in commands:
        state = apply(state, cmd)
        if done(state):
            break
    return render(state)
```

`apply` 里只用 `if / elif` 把题面规则逐条翻译。规则超过三种时，先写字典映射，再写分支。九宫格按键、骰子转向、货币单位、牌面大小，全是映射表。

```python
FACE = {"L": swap_left, "R": swap_right, "F": swap_front, "B": swap_back}
```

映射表写在函数外面，分支里只留题面真正的例外。

## 三种状态够覆盖这一类

**一条序列。** 字符串、列表、光标下标。代码编辑器的 `FORWARD / BACKWARD / SEARCH`，五键键盘的选区、剪贴板，屏保的坐标和速度符号，都属于这个。光标先夹紧到 `[0, len]`，再执行命令。

```python
cursor = min(len(text), max(0, cursor + delta))
```

**若干个桶。** 打印机是「打印机编号 → 堆」，内存池是「大小 → 剩余块数」，站点是「时刻 → 人数」。桶用 `defaultdict`。优先打印是桶里放堆，堆的写法在 01，不要在仿真里再发明一个排序。

**一张表，外加合法性检查。** 扑克牌型、斗地主顺子、考勤是否异常、IPv4 是否合法。先把输入收成结构化字段，再按题面给的顺序做判断。判断顺序就是规则优先级：同花顺要写在同花和顺子前面，因为两个条件同时成立才是同花顺。

非法输入单独一条返回。本题库的返回值不统一，以题面为准：`invalid IP`、`ERROR!`、`-1`、`No`。

## 栈：仿真用的内存

下面这些题的状态就是栈。不要另起一个「栈专题」去背定义。问自己：当前字符能不能把前面已经放下的东西消掉、配上、或者展开？能，就用栈。

| 题面 | 栈里放什么 | 什么时候弹 |
| --- | --- | --- |
| 括号是否匹配、最大深度 | 左括号 | 右括号和栈顶成对 |
| 消消乐、相邻字母删除 | 还没被消的字符 | 栈顶和当前相同 |
| 压缩串 `3[a2[c]]` | 左括号前的串和重复次数 | 遇见 `]` |
| 表达式、仿 LISP | 运算符和操作数 | 遇见右括号或空格边界 |
| 去掉 k 位得到最小数 | 还保留的数字 | 栈顶比当前大，并且还剩删除次数 |

括号：

```python
PAIR = {")": "(", "]": "[", "}": "{"}

def solve_method(s):
    stack = []
    depth = 0
    for ch in s:
        if ch in "([{":
            stack.append(ch)
            depth = max(depth, len(stack))
        elif ch in PAIR:
            if not stack or stack[-1] != PAIR[ch]:
                return 0
            stack.pop()
    return depth if not stack else 0
```

相邻消除。循环删除用栈，不要在列表中间 `pop`，否则每删一次都在挪后面的元素：

```python
stack = []
for ch in s:
    if stack and stack[-1] == ch:
        stack.pop()
    else:
        stack.append(ch)
```

压缩展开。数字可能多位，先攒数字，遇到 `[` 把「之前的串、重复次数」压进去，遇到 `]` 再拼：

```python
stack = []
cur = ""
num = 0
for ch in s:
    if ch.isdigit():
        num = num * 10 + int(ch)
    elif ch == "[":
        stack.append((cur, num))
        cur, num = "", 0
    elif ch == "]":
        prev, times = stack.pop()
        cur = prev + cur * times
    else:
        cur += ch
```

最小数。从左到右，栈要保持递增，弹出的前提是「还删得动」：

```python
stack = []
for ch in num:
    while stack and removed < k and stack[-1] > ch:
        stack.pop()
        removed += 1
    stack.append(ch)
stack = stack[: len(stack) - (k - removed)]
```

结果要去掉前导 0。删完仍为空，返回 `"0"`。

## 报文和进制

这一类是仿真里最容易写长的。处理顺序固定成四步，不要边解析边算业务。

1. 校验整体形状：段数、字符集、范围。不合法立刻返回题面指定的字符串。
2. 把一段切成字段。TLV 按「标签、长度、值」走指针；长度是小端还是大端看题面，不要凭记忆。
3. 字段换算。IPv4 是每段占 8 位往左移；N 进制用 `int(s, base)` 读进来，写回去用除余。
4. 按题面格式拼回去。

除余写回 N 进制：

```python
def to_base(n, base):
    if n == 0:
        return "0"
    digits = []
    while n:
        digits.append(str(n % base))
        n //= base
    return "".join(reversed(digits))
```

位运算只在题面把「与、或、异或、某一段 bit」写成规则时使用。报文响应时间取某一段位：先 `&` 掩码，再 `>>`。不要把位运算当成独立算法去找题。

## 时间往前走

屏保、绘图面积、喊七、报数、约瑟夫，都是「时钟跳一格，状态跟着变」。

```python
x = y = 0
dx = dy = 1
for _ in range(t):
    x += dx
    y += dy
    if x in (0, width) or y in (0, height):
        dx, dy = -dx, -dy
```

撞边只反转对应那条轴的速度。先移动再判断，还是先判断再移动，用样例的第一步对一下，两种差一格。

环形报数不要真的去旋转列表。用一个存活列表加下标：

```python
i = 0
while len(people) > 1:
    i = (i + m - 1) % len(people)
    people.pop(i)
```

`pop` 之后下一个元素已经滑到下标 `i`，所以 `i` 不要再 `+1`。

## 写的时候对三件事

- 规则的先后顺序跟题面一致。同花顺、满减和折扣、版本号从左到右，顺序反了样例能过、隐藏数据不过。
- 指针和光标先夹到合法区间，再执行。`SEARCH` 找不到时指针停在哪，题面有一句，单独写。
- 栈题的空栈。右括号来时栈空，返回题面的失败值，不要 `stack[-1]`。
