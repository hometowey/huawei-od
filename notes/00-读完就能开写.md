# 读完就能开写

这套笔记对着 `codes/` 里 321 道解法整理，目标只有一个：合上笔记之后，看到本题库里的题，90 秒内决定写哪一种循环，并且把骨架默写出来。

不要按「语法 / 算法 / 框架」三块背。本仓库里，算法名和要写的循环是同一件事。先背这篇的四问，再按问到的那一页把骨架写熟。

`codes/` 里的函数叫 `solve_method`，用 `assert` 对样例。考场上改成读标准输入、写标准输出，读法在 01。

## 先看数据范围

范围决定你有没有资格上「漂亮算法」。本题库大量 100 分题的标答就是两层循环。

| 规模 | 考场上允许的写法 |
| --- | --- |
| n ≤ 20 | 回溯、全排列、`2^n` 枚举 |
| n ≤ 100 | 可以 `n^3`，网格 DFS 随便写 |
| n ≤ 1000 | 停在 `n^2`，或 `n^2` 套一个小常数 |
| n ≤ 1e5 | 排序、堆、双指针、前缀和、二分，禁止两层裸循环 |
| 字符集、格子很小 | 先建映射表，再谈搜索 |

样例能手算出来、又能写成一行公式的，直接写公式。工号位数用对数，连续整数求和用等差数列，分苹果用异或，出租车费是「没有数字 4」的进制。这些题没有第二层算法。

## 四问，命中就停

按顺序问。先命中的那个就是这题的写法，不要再往下找更高级的名字。

**一、状态能不能被指令一条条改出来？**

题面出现命令、报文、牌型、键盘、编辑器、棋盘落子、时间往前走一格。手里有一份状态（字符串、坐标、栈、字典），每读一条就改一次，最后格式化输出。

去 [02-仿真与栈](02-仿真与栈.md)。括号、消消乐、压缩展开也在这里：栈只是仿真用的内存。

**二、把对象排个序之后，答案是不是扫一遍就有了？**

「第 k 个」「离得最近的 k 个」「谁和谁配对」「重叠区间合成一段」「某时刻有多少人」。排序键、双指针、区间合并、差分，都是「先变成有序，再线性扫」。

去 [03-排完序再扫](03-排完序再扫.md)。

**三、答案是一段连续区间，还是一个单调的临界值？**

- 子串、子数组、窗口里的个数或最值，左右边界能滑动：窗口。
- 问最小速度、最大间距、最少天数，而且这个数变大之后可行性只朝一个方向变：二分答案。外面套二分，里面写一个 `ok(mid)`。

去 [04-窗口与二分](04-窗口与二分.md)。

**四、剩下的只有两类。**

- 格子、图、连通块、从一点扩散、要把方案枚举出来：搜索。连通块标记了不要撤销；数步数用队列；组合方案要撤销。去 [05-格子与枚举](05-格子与枚举.md)。
- 「前 i 件物品 / 前 i 天 / 走到第 i 格」的最优只由更短的前缀决定：填一张表。去 [06-填表](06-填表.md)。先用一句话写出 `dp[i]` 是什么，再写循环。本仓库的 DP 题都是这个顺序。

四问都像，用这个裁决：

- 要步数、要层数，用队列，不用递归。
- 只问连通或最大块，用 DFS 染色，不要建最短路。
- n 很小却在写背包，先看是不是回溯更短。充电方案、组装数组、短信条数，本题库用的是回溯。
- 容量限制下求一个最优数，物品只能取一次，才是 01 背包。充电功率、软盘、砝码是这一类。

## 开写之后的固定顺序

1. 用 01 的读入把样例读进来，先 `print` 确认拆对了。本题库一半的错误都出在分隔符：空格、逗号、方括号、多行矩阵。
2. 把上面命中的骨架抄下来，先让样例过。
3. 再补题面里的附加规则：字典序、下标最小、并列时 id 更小、输出 `-1` 还是 `No`。
4. 空数组、单元素、全部相同、刚好等于边界，各看一眼。

100 分题不要在骨架之外再发明结构。200 分题先确认落在哪一问，再写；范围允许时，先写能过样例的直白版本。

## 合上笔记要能默写的 10 段

能不看笔记写出下面 10 段，这套题库里的题就有下手的地方。每段的完整形态和例题在对应页。

1. 三种读入：空格行、逗号行、`n` 行矩阵。
2. `Counter` 加 `sorted(..., key=...)` 的多关键字。
3. 排序后的左右指针配对。
4. 区间合并。
5. 差分：时刻 `+1`、结束 `+1` 处 `-1`，再前缀和。
6. 不定长滑动窗口。
7. 二分答案：`ok(mid)` 为真就收紧一侧。
8. 四方向 DFS，访问过就改格子。
9. 队列 BFS，一层一层计步数。
10. 01 背包一维倒序，或括号栈。

第 10 段两个都要会。背包和栈是本题库里仅有的两个「名字固定、代码也固定」的模板，其余题都是上面 1 到 9 的变体。
