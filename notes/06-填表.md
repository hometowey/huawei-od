# 填表

四问里的第四问后半。能用一句话说完「`dp[i]` 表示前 i 个里的最优」，并且它只由更小的 i 算出来，就填表。说不出这句话，就还在 02 到 05 里。

本题库真正在填的表就这几张。先把中文句子写在注释里，再写循环，和 `codes/` 里的解法同一个顺序。

容量大、物品多、只要一个数：填表。n ≤ 20 还要把方案打印出来：回到 05 的回溯。最大报酬、充电功率、软盘、砝码是表；销售方案、K 个数的组合是回溯。

## 01 背包：选或不选一次

充电设备组合、软盘拷文件、称砝码。`dp[j]` 是容量不超过 j 时的最优。

```python
def knapsack(weights, values, cap):
    dp = [0] * (cap + 1)
    for w, v in zip(weights, values):
        for j in range(cap, w - 1, -1):
            dp[j] = max(dp[j], dp[j - w] + v)
    return dp[cap]
```

倒序是因为每件物品只能用一次。正序会把同一件用很多次。

只要「能不能称出重量 j」，把 `max` 换成布尔：

```python
dp = [False] * (cap + 1)
dp[0] = True
for w in weights:
    for j in range(cap, w - 1, -1):
        dp[j] = dp[j] or dp[j - w]
```

价值和重量是同一个数时（充电功率、文件大小），`v = w`。二维写法本题库也有，`dp[i][j]` 表示前 i 件、容量 j。考场上写一维就够，除非你要回溯出选了哪几件。

## 爬台阶，和环形不能相邻

猴子爬山：到第 i 阶的方法数，来自 i-1 和 i-3。

```python
dp = [0] * (n + 1)
dp[0] = 1
for i in range(1, n + 1):
    dp[i] += dp[i - 1]
    if i >= 3:
        dp[i] += dp[i - 3]
```

初始值用样例最小的 n 对一下。到第 1 阶是 1 种还是 0 种，题面的「第 0 阶算不算起点」会改 `dp[0]`。

跳格子（2）是打家劫舍：相邻不能同时拿。

```python
def rob_line(nums):
    if not nums:
        return 0
    prev2, prev1 = 0, 0
    for x in nums:
        prev2, prev1 = prev1, max(prev1, prev2 + x)
    return prev1
```

环形：第一格和最后一格不能同时拿。算两次，一次丢掉最后一格，一次丢掉第一格，取最大。

```python
return max(rob_line(nums[:-1]), rob_line(nums[1:]), nums[0])
```

只有一格时 `nums[:-1]` 是空的，所以要和 `nums[0]` 取最大。

## 持有或不持有

最大报酬、股票收益、贪心的商人。名字像贪心，状态是两列。`dp[i][0]` 当天结束时手里有货，`dp[i][1]` 当天结束时手里没货。

```python
def max_profit(prices):
    hold, empty = -prices[0], 0
    for p in prices[1:]:
        hold = max(hold, empty - p)     # 继续拿着，或今天买入
        empty = max(empty, hold + p)    # 继续空仓，或今天卖出
    return empty
```

只能买一次时，买入只能从「从来没买过」转移，用一个单独的 `empty_before_buy`，不要从已经卖过的 `empty` 再买。题面有「只能交易一次 / 可以多次 / 卖出后要冷冻一天」，这三句对应三种转移，写之前在注释里圈出来。本题库商人是按商品分别做，每种商品自己跑一遍这个转移。

玩牌高手是带冷却的线性表：选这一张，就要从三轮之前的分数接上；不选，就继承上一轮。注释先写「跳过的代价是回到 i-3」，再写 `max`。

## 连续子串和最大子矩阵

找出重复代码。题面写子序列，[008 找出重复代码](../docs/choice100/008_find-duplicate-codes.md) 的表实际求的是连续子串：只有当前字符相等才从左上角加 1，并且要记结束位置把子串切出来。考场先看示例，公共部分必须挨在一起，就是子串。

```python
def longest_common_substring(a, b):
    dp = [[0] * (len(b) + 1) for _ in range(len(a) + 1)]
    best = end = 0
    for i in range(1, len(a) + 1):
        for j in range(1, len(b) + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
                if dp[i][j] > best:
                    best = dp[i][j]
                    end = i
    return a[end - best:end]
```

真正的子序列不要求连续，不等时要 `max(dp[i-1][j], dp[i][j-1])`。本题库这道不要写成子序列。

最大子矩阵：枚举上边界和下边界，把这两行之间压成一维列和，再对这一维做最大子数组和。

```python
def kadane(a):
    best = cur = a[0]
    for x in a[1:]:
        cur = x if cur < 0 else cur + x
        best = max(best, cur)
    return best

def max_submatrix(grid):
    n, m = len(grid), len(grid[0])
    best = grid[0][0]
    for top in range(n):
        col = [0] * m
        for bottom in range(top, n):
            for j in range(m):
                col[j] += grid[bottom][j]
            best = max(best, kadane(col))
    return best
```

全是负数时，`kadane` 里的 `cur = x if cur < 0 else cur + x` 会落到最大的那个负数。样例若有全负，先看这一行。

## 一行能递推完的

外卖员上楼：偶数层来自走楼梯或从一半楼层乘电梯，奇数层要再多走一层。`dp[i]` 是到第 i 层的最短时间，按 i 从小到大填。

超级玛丽过桥：`dp[i][j]` 是走到第 i 块板、还剩 j 点生命的走法。转移是从 i-1、i-2、i-3 过来，踩到陷阱就把生命下标减 1。这是爬台阶加上一个生命维度，不是新模型。

士兵过河：经典的「每次两个人，船要开回来」。先排序，`dp[i]` 是前 i 个最慢的人都过去的时间。转移题面固定两种策略，取最小：最快的来回接，或者最快和次快配合把最慢的两个送走。这种题把两种策略写在注释里再编码，不要现场推。

递增字符串：枚举分界点 i，左边全改成 A 的代价加右边全改成 B 的代价。代价用前缀里 A 的个数 O(1) 算出来。这是前缀和，表只有一维计数。

## 写的时候对三件事

- 注释里的那句中文和循环的方向一致。`dp[j]` 依赖 `dp[j - w]`，容量就必须从大到小，否则用到的是本轮已经更新过的值。
- 初始化。方法数的 `dp[0] = 1`，最短路式的表先填一个很大的数，最优利润的持有状态从第一天买入开始是负数。用最小样例把 `dp` 打印出来再交。
- 二维表的尺寸是 `n + 1`，循环从 1 开始，物品用 `a[i - 1]`。差一格是这一页最常见的错误。
