# 窗口与二分

四问里的第三问。这两类写出来都是「一段范围加一个判断」，所以放在一页。用一句分开：

- 答案是原数组上的一段下标，边界会滑动：窗口。
- 答案是一个数值，这个数值变大后，`ok` 只会从假变成真，或从真变成假：二分。

窗口移动的是下标。二分移动的是答案。不要在施肥机、供餐速度上写滑动窗口，也不要在子串上二分下标，除非那一段的可行性真的单调。

## 固定长度的窗口

窗口长度题面给死了：知识图谱新词、关联字串、滑动窗口最大和、最差产品奖取每个窗口的最小值。

长度 `k`，数据范围到几千时，每个窗口重新 `Counter` 或重新求和都可以。本题库标答就是这样。

```python
def count_anagram(content, word):
    k = len(word)
    target = Counter(word)
    ans = 0
    for i in range(len(content) - k + 1):
        if Counter(content[i:i + k]) == target:
            ans += 1
    return ans
```

范围到 1e5，改成维护一个计数，右端进来、左端出去，不要每个窗口重建：

```python
window = Counter(s[:k])
# 比较 window 和 target
for right in range(k, len(s)):
    window[s[right]] += 1
    left_ch = s[right - k]
    window[left_ch] -= 1
    if window[left_ch] == 0:
        del window[left_ch]
```

窗口最小值若只要每个位置的答案、且 k 和 n 都大，用单调队列。本题库「最差产品奖」的范围允许每个窗口扫一遍取 `min`。先写 `min(scores[i:i+k])`，超时再换单调队列。

## 不定长窗口

补种胡杨、获得完美走位、符合条件的子串长度、区块链文件转储、子序列和恰好等于目标。特征：右端尽量往右，一旦不满足就把左端收回来。

右端扩展，左端在 `while` 里收缩。答案在收缩的时候更新，还是在扩展的时候更新，看题面要的是「满足条件的最长」还是「满足条件的最短」。

最长的、和不超过上限：

```python
def longest_at_most(nums, limit):
    left = cur = best = 0
    for right, x in enumerate(nums):
        cur += x
        while cur > limit:
            cur -= nums[left]
            left += 1
        best = max(best, right - left + 1)
    return best
```

最短的、窗口必须盖住目标字符：

```python
def shortest_cover(s, need_cnt):
    left = 0
    best = len(s) + 1
    window = Counter()
    formed = 0
    for right, ch in enumerate(s):
        window[ch] += 1
        if window[ch] == need_cnt[ch]:
            formed += 1
        while formed == len(need_cnt):
            best = min(best, right - left + 1)
            c = s[left]
            if window[c] == need_cnt[c]:
                formed -= 1
            window[c] -= 1
            left += 1
    return best if best <= len(s) else -1
```

完美走位是这个骨架的变体：窗口里放的是「多出来的字符」，收缩到每种字符的盈亏都变成 0，记录的是最短替换长度。先写「窗口内计数是否平衡」这个判断，再套上面的收缩。

和恰好等于目标、要最长：收缩条件改成 `cur > target`，在 `cur == target` 时更新答案。子序列长度那题是这个。

胡杨补种可以看成：窗口里最多允许 k 个 0（死树），求最长。`while` 的条件是窗口内 0 的个数大于 k。

## 二分答案

最小施肥机能效、植树间距、食堂供餐速度、服务中心位置、统一限载。题面里的词是「最小的最大」「最大的最小」「至少」「不超过天数」。

外层永远是同一段。变的只有两处：搜索范围，和 `ok(mid)`。

求最小的可行值（速度、能效，越大越容易完成）：

```python
def solve_method(limit, nums):
    lo, hi = 1, max(nums)
    ans = -1
    while lo <= hi:
        mid = (lo + hi) // 2
        if ok(mid, nums, limit):
            ans = mid
            hi = mid - 1
        else:
            lo = mid + 1
    return ans
```

求最大的可行值（间距，越大越难种够棵数）：`ok` 为真时 `lo = mid + 1`，并且 `ans = mid`。方向只由一句话决定：mid 变大，`ok` 变真，就往左收；mid 变大，`ok` 变假，就往右收。

施肥的 `ok` 是天数。单块地需要 `(x + mid - 1) // mid` 天，总和不超过给的天数：

```python
def ok(speed, fields, days):
    return sum((x + speed - 1) // speed for x in fields) <= days
```

植树的 `ok` 是：按这个最小间距，从左到右能放下的棵数不少于要求。贪心放，能放就放，这是 `ok` 里面的内容，不是另一道题。

```python
def ok(dist, pits, need):
    count = 1
    last = pits[0]
    for x in pits[1:]:
        if x - last >= dist:
            count += 1
            last = x
    return count >= need
```

服务中心那类「在值域上找一个点，使距离和最小」，值域单调时同样二分这个点，`ok` 换成「再往右走，距离和是否开始变大」。如果距离和不是单峰的，就不要二分，排序取中位数，回到 03。新学校选址是中位数，不是二分。

## 怎么选

| 你在题面里看到 | 写 |
| --- | --- |
| 窗口长度是定值 k | 固定窗口 |
| 找最短覆盖、最长且不超过 k 次 | 不定长窗口，一边扩展一边收缩 |
| 最小速度、最大间距，且可行性单调 | 二分，先写 `ok` |
| 问的是位置而不是数值，例如第几个下标 | 先看 03，多数是排序或前缀和 |

前缀和单独记一行，因为它经常被误判成窗口。阿里巴巴宝箱（1）左右和相等、数组中心位置：先 `total = sum(a)`，扫的时候维护左边的和，右边用总和去减。这是一次线性扫描，不是窗口。

```python
left = 0
total = sum(a)
for i, x in enumerate(a):
    right = total - left - x
    if left == right:
        return i
    left += x
return -1
```

## 写的时候对三件事

- `ok(mid)` 先用样例里那个已知答案代进去，看它返回真。方向写反时，样例会落到边界上，看起来像差 1。
- 窗口收缩用 `while`，不用 `if`。一次扩展可能要连着收缩好几格。
- 左端已经超过右端时，和要归零，计数里的 0 要删掉再和目标 `Counter` 比较。`Counter` 里留着若干个 0，和另一个没有这些键的 `Counter` 不相等。
