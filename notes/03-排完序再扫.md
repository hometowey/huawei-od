# 排完序再扫

四问里的第二问。题面问的是顺序、配对、重叠、第 k 个、某一时刻的人数。做法是先把数据变成有序的，再从头扫到尾，扫的时候只看当前位置和它的邻居。

这一页的四种扫法共用一个前提：无序时别动手。先 `sort`，或者先用差分把「变化点」排好。

## 多关键字，排完取前 k

优秀学员、酒店预订、身高体重、热词、磁盘容量、射击取前三。比较规则写进 `key` 的元组里，取前 k 即可。语法在 01，这里只记裁决：

- 题面每说一个「相同则再比……」，元组里就多一个字段。
- 降序用负数，全部字段留在同一次排序里。
- 只要前 k 个，排完切片，不要再扫一遍找最大值。

```python
people.sort(key=lambda p: (-p.checkins, p.first_time, p.eid))
return [p.eid for p in people[:5]]
```

组成最大数、组成最小数是排序，但键不是字段，是拼接：

```python
from functools import cmp_to_key

def solve_method(nums):
    arr = [str(x) for x in nums]
    arr.sort(key=cmp_to_key(lambda a, b: (a + b > b + a) - (a + b < b + a)))
    # 最小数：比较符反过来，并处理前导 0
    return "".join(arr)
```

`(a+b > b+a) - (a+b < b+a)` 得到 `1 / -1 / 0`，给 `cmp_to_key` 用。

中位数也是这一类。新学校选址、众数再取中位数：排序后按下标取。偶数个时本题库「选址」取靠前那个中位，先看题面要的是下标还是下标上的值。

```python
a.sort()
return a[(len(a) - 1) // 2]
```

## 左右指针：排序后的配对

租车骑绿岛、能力组队、双十一凑金额、跳房子凑步数。特征是：排好序以后，太小就动左端，太大就动右端。

两人一车，体重和有上限，问最少几辆：

```python
def solve_method(limit, weights):
    a = sorted(weights)
    i, j = 0, len(a) - 1
    cars = 0
    while i <= j:
        if i < j and a[i] + a[j] <= limit:
            i += 1
        j -= 1
        cars += 1
    return cars
```

三数之和是同一根指针，外面多一层固定一个数。双十一、跳房子（2）都是这样。先排序，枚举 `k`，`i = k+1`，`j = n-1`：

```python
a.sort()
best = None
for k in range(n):
    i, j = k + 1, n - 1
    while i < j:
        s = a[k] + a[i] + a[j]
        if s == target and better(k, i, j):
            best = (k, i, j)
        if s < target:
            i += 1
        else:
            j -= 1
```

和偏小，左指针右移；和偏大，右指针左移。要字典序最小或下标和最小时，把这个条件放进 `better`，不要排完再过滤。

两数之和绝对值最小、乱序里找最接近的一对：可以双指针，也可以 n 很小时直接两层循环。先看范围。n ≤ 1000 时两层循环更不容易写错，本题库「两数之和绝对值最小」就是两层循环。

## 区间合并

VLAN 资源池、端口、演出场次、连接器。先按左端点排序，再决定当前段能不能往后延。

```python
def merge(segs):
    segs = sorted(segs)
    ans = []
    for L, R in segs:
        if not ans or ans[-1][1] < L:
            ans.append([L, R])
        else:
            ans[-1][1] = max(ans[-1][1], R)
    return ans
```

题面说「相邻也算连通」（3 和 4 要合成一段）时，判断改成 `ans[-1][1] + 1 < L`。VLAN 就是相邻也合并。

端口合并看的是集合相交，不是数字区间。两个集合的交集不少于 2 个就并成一个，用循环合并，数据量很小：

```python
def overlap(a, b):
    return len(set(a) & set(b)) >= 2
```

看演出、活动选择：按结束时间排序，能接上就选。这是区间题里唯一「不合并、只计数」的扫法。

```python
shows.sort(key=lambda s: s[1])
end = -1
count = 0
for start, finish in shows:
    if start >= end + gap:
        count += 1
        end = finish
```

`gap` 看题面。文艺汇演要留 15 分钟，就写成 `start >= end + 15`。

## 差分：某一时刻有多少

站点人数、任务混部、服务器耗能、日志积分这一类「区间加到一条时间线上」。不要对每个时刻去扫所有区间。

```python
from collections import defaultdict

diff = defaultdict(int)
for start, end in intervals:
    diff[start] += 1
    diff[end + 1] -= 1          # 左闭右开。右端点也算的话，改成 end+1

cur = best = 0
for t in sorted(diff):
    cur += diff[t]
    best = max(best, cur)
```

右端点算不算，用样例一个区间对一下。题目说「离开车站的那一站还在车上」，右端点要算，`-1` 打在 `end + 1`。

扫描线上要记录「是谁」而不只是人数时，把事件拆成 `(时刻, +1/-1, 编号)` 再排序。同一时刻先处理下线还是先处理上线，题面会改变答案，写进排序键里，不要靠稳定排序碰运气。

## 贪心就这一句话

本题库里名叫贪心的题，扫的时候都是同一句：排好之后，当前这个选或不选，只看它和上一个已经选定的谁更优，不回头。

- 补最短的木板：排序后总是加当前最短的，加完如果不再是最短就看下一个。
- 快递货车：重量从小到大装，超重就停。
- 拔河、篮球分队：能力从高到低，分给当前总和更小的那一队。
- 田忌式比大小：排序后，赢不了对方当前最小的，就用自己最小的去换掉对方最大的。

写不出「当前这一步为什么不用回头」，就不要叫它贪心，回到四问，多半是背包或回溯。最大报酬、商人利润名字里带贪心，本题库的代码是填表，在 06。

## 写的时候对三件事

- 左闭右开。区间合并、差分、滑动窗口的右端点，三种写法差 1。用第一个样例的长度验。
- 并列。题面只要出现「相同则」，`key` 里就必须有下一项。只排主关键字，隐藏数据会在并列处打散。
- 指针不要交叉之后还各加一次。`while i <= j` 和 `while i < j` 差在「最后落单的那一个算不算」。租车里落单的人自己一辆，条件用 `i <= j`。
